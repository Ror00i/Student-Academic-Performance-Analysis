# Student Performance Analysis

## Project Overview
This project was developed as part of a university Data Collection and Processing course. The goal was to analyze students' academic performance and explore factors that may influence their final scores.

## Tools & Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook

## Project Workflow
- Data loading and inspection
- Data cleaning and preprocessing
- Exploratory Data Analysis (EDA)
- Data visualization and correlation analysis
- Outlier detection using the IQR method
- Data scaling and categorical encoding
- Feature engineering and feature selection
- Dimensionality reduction using PCA

## Key Findings
The analysis highlighted the importance of previous academic performance, attendance, and homework completion in understanding students' final scores.
